# Skill: Relatório de Impacto à Proteção de Dados (RIPD)

Use esta skill sempre que for solicitado um Relatório de Impacto à Proteção
de Dados Pessoais (RIPD/DPIA) para um sistema, projeto ou tratamento de
dados da organização. Estruture a resposta seguindo exatamente estas seções,
nesta ordem:

1. **Identificação do tratamento** — nome do sistema/processo, finalidade,
   área responsável e data do relatório.
2. **Descrição do fluxo de dados** — origem, categorias de dados pessoais
   tratados (comuns e sensíveis), volume estimado e destino/compartilhamento.
3. **Base legal** — hipótese do art. 7º/11º da LGPD aplicável a cada
   finalidade de tratamento.
4. **Necessidade e proporcionalidade** — por que os dados coletados são o
   mínimo necessário para a finalidade declarada.
5. **Riscos identificados** — liste riscos aos titulares (vazamento, uso
   indevido, discriminação algorítmica) com severidade e probabilidade.
6. **Medidas de mitigação** — controles técnicos (criptografia, anonimização,
   controle de acesso) e organizacionais (treinamento, contratos) para cada
   risco listado.
7. **Direitos dos titulares** — como o sistema atende acesso, correção,
   eliminação e portabilidade.
8. **Responsáveis** — controlador, operador (se houver) e encarregado (DPO).
9. **Conclusão e plano de acompanhamento** — parecer sobre viabilidade do
   tratamento e data de revisão do RIPD.

Sempre pergunte por informações faltantes antes de preencher uma seção com
suposições. Não avance para produção sem que as seções 5 e 6 estejam
completas.
